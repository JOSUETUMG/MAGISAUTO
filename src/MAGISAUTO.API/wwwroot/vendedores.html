VENDEDORES

Agregar vendedor

El código interno se asigna automáticamente.

Si el DPI ya está registrado, usa sus nombres y apellidos existentes. Al editar nombres se actualiza la ficha personal compartida con sus otros roles.

El DPI se conserva al editar; no se sustituye la persona del vendedor. Si no hay agencias, agrega una desde el catálogo Agencias antes de guardar.

ELIMINAR VENDEDOR

¿Eliminar este vendedor?

Se retira el registro de vendedor. La ficha de la persona se conserva para sus otros roles.
